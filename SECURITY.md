# Security Policy

## Supported Versions

This repository is maintained as a research-oriented project. At this stage, security updates are applied only to the latest version available on the `main` branch.

| Version | Supported |
| ------- | --------- |
| main    | ✅        |
| older versions | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability related to this repository, please do not disclose it publicly at first.

Instead, please report it privately through GitHub Security Advisories for this repository. Do not include exploit details in a public issue.

When reporting a vulnerability, please include:

- A clear description of the issue
- The affected file, module, or workflow
- Steps to reproduce the problem, if applicable
- Any suggestions that may help understand or mitigate the issue

You can expect an initial response within a reasonable time, depending on availability.

Please note that this repository is primarily intended for research purposes. While reasonable efforts will be made to review and address valid security concerns, no formal security support or guarantee is provided.
